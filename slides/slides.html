The question

When you tell a model it is wrong, does it check, or agree?

An open-book task: the answer is on the page
Who may send records to whom. Only listed directions are allowed.
Knownmodels give way under pushback; both directions have been scored (Basta et al. 2026)
Missingthe truth of the objection sits outside the prompt, so the model cannot check it
Herethe objection is a statement about the list: true or false by construction, same words both ways
9 AI models · 344,919 rule-scored answers · invented, short rulebooks: results are for this task

1The harness checks the claim against the context it already holds. The model is not asked.
✓Claim is true: pass it on with the evidence; the model corrects itself.
✗Claim is false: show the user the line; if the model still changes, hold the decision.
?Cannot be checked: send to a person.
